# Titanic Dataset – Data Cleaning and Preprocessing

## Project Overview
This project focuses on cleaning and preprocessing the Titanic dataset using Python.

## Objective
To clean raw data and prepare it for further analysis.

## Tools Used
- Python
- Google Colab
- Pandas
- NumPy

## Dataset
Titanic Dataset – 891 passenger records.

## Steps Performed
1. Imported required libraries.
2. Loaded the Titanic dataset.
3. Identified missing values.
4. Handled missing values using median and mode.
5. Removed the Cabin column due to a high number of missing values.
6. Checked and removed duplicate records.
7. Converted data types.
8. Renamed columns.
9. Verified the cleaned dataset.
10. Exported the cleaned dataset as a CSV file.

## Results
- Missing values handled.
- Duplicate records checked.
- Data types converted.
- Columns renamed.
- Cleaned dataset exported successfully.
